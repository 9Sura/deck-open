# DECK

Free, AI-generated DECA practice: generated practice tests, a browsable bank of
16,283 questions, event vocabulary, daily roleplays, and progress / error-log
analytics.

**Not affiliated with DECA Inc.** DECA is a trademark of DECA Inc. Every piece of
practice material here is original and AI-generated; none of it is official DECA
content.

---

## What this is

Two halves that meet through committed data files:

- **`frontend/`** — the Next.js app students use.
- **`backend/`** — Python tools that *author* the study material offline and
  commit it into the app's `public/` tree.

**There is no runtime model compute in the app.** It never calls a model, never
needs an API key, and only ever reads data that is already in this repository.
That is why it runs from a clone with nothing configured.

```
deck-open/
├── frontend/                       # Next.js 16 app — what students use
│   ├── app/                        # routes: / , /test-generator , /question-bank , /vocab ,
│   │                               #   /roleplay , /progress , /review , plus static pages
│   │                               #   (/developers , /privacy , /terms , /changelog , /help)
│   ├── components/                 # UI: hand-drawn notebook look-primitives, ui/, page pieces
│   ├── hooks/                      # shared React hooks
│   ├── lib/                        # ProgressStore, route gating, themes, DECA mirrors
│   ├── public/question-bank/       # THE question bank — canonical, served verbatim (16,283 questions)
│   ├── public/vocab/               # event vocab catalogs (28 events, 7,000 terms)
│   ├── public/roleplays/           # roleplay bank + the dealt day files
│   ├── scripts/                    # derive-bank-artifacts.mjs, sync-vocab.mjs, check-data-sync.mjs
│   └── supabase/migrations/        # schema for the optional accounts feature
│
├── backend/                        # offline authoring tools — never runs in production
│   ├── test-gen-model/
│   │   ├── src/                    # practice-exam pipeline: generators/ + prompts/
│   │   └── data/                   # NOT published — real DECA exams + PI library (see its README)
│   ├── roleplay-gen-model/
│   │   ├── src/                    # fill_bank.py (authoring driver), icdc_gate.py (quality bar), prompts/
│   │   └── data/                   # NOT published — real DECA roleplays + PI library (see its README)
│   └── feat-vocab/                 # vocab catalog + source data, synced into public/vocab/
│
└── docs/                           # user manual + reference
```

## Current data

Counted from disk — count it yourself rather than trusting these numbers:

| What | Where | Size |
|------|-------|------|
| Questions | `frontend/public/question-bank/` | 16,283 across 5 clusters (finance, marketing, entrepreneurship, pbm, hospitality) |
| Vocab | `frontend/public/vocab/` | 7,000 terms across 28 event catalogs (250 each) |
| Roleplays | `frontend/public/roleplays/bank/` | 60 banked, on 2 of 28 event shelves — the bank is mid-regeneration |

Recount the bank any time:

```bash
python3 -c "import json,glob,os;print(sum(len(json.load(open(p))) for p in glob.glob('frontend/public/question-bank/*/*.json') if os.path.basename(p)!='manifest.json'))"
```

## A note on the practice material

Every question, explanation, vocabulary entry and roleplay in this repository was
generated by a language model and reviewed by automated gates — not by DECA, and
not by a teacher. It is study material, not an answer key. Treat a disagreement
between this bank and your competition guide as the guide being right.
